# Предложения по улучшению

## Авторизация и права доступа

- Аутентификация (JWT или сессионная).
- RBAC: администратор / инспектор / наблюдатель.
- Аудит действий: кто, когда, что создал/изменил/удалил.

## Работа с СМП

- Расширенная карточка: ОГРН, адрес, регион, ОКВЭД, контакты, категория.
- Отдельный раздел «Реестр СМП» (CRUD).
- Импорт реестра СМП.
- Дедупликация по ИНН/ОГРН.

## Excel

- Многостраничный экспорт (>1 млн строк).
- Предпросмотр импорта перед сохранением.
- Выбор поведения при отсутствии СМП: откат или автосоздание.
- Идемпотентность импорта (по хэшу файла).
- Экспорт в CSV.
- Экспорт в PDF.
- Хранение файлов экспорта в S3.

## Справочники

- Вынос типов проверок и статусов в БД.
- Справочник контролирующих органов.
- Справочник регионов.

## Производительность

- Полнотекстовый поиск (tsvector / pg_trgm) вместо ILIKE.
- Кэширование справочников (Redis).
- Виртуализация списка на фронте.
- Составные индексы под частые фильтры.
- Курсорная пагинация для больших выборок.

## UX

- Сохранение фильтров в localStorage.
- Кастомный datepicker.
- Массовые операции (выделение + групповое действие).
- Уведомления о приближении проверок (email/telegram).
- Тёмная тема.
- Настройка видимых колонок.

## Технические улучшения

- E2E-тесты (Playwright/Cypress).
- Unit-тесты на парсер Excel и валидаторы.
- CI/CD (GitHub Actions).
- Метрики (Prometheus), structured logs.
- Rate limiting на API.
- Версионирование API (уже есть /api/v1, нужна политика deprecation).
- Healthcheck `/api/health`.
- Интеграция Sentry.

## Безопасность

- Ограничить CORS по домену в проде.
- Rate limiting на импорт.
- Проверка MIME-типа Excel, не только расширения.
- Санитизация HTML в полях.
- HTTPS (mkcert локально, Let's Encrypt в проде).
