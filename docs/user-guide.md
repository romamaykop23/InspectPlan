## Общее описание

Приложение — реестр плановых проверок субъектов малого предпринимательства (СМП).

Основной экран — **Перечень плановых проверок** — открывается автоматически. Сверху — фильтры и кнопки действий, ниже — таблица.

На мобильных таблица превращается в карточки.

## Перечень плановых проверок

| Колонка   | Описание                                              |
| --------- | ----------------------------------------------------- |
| #         | Порядковый номер на странице                          |
| СМП       | Наименование СМП                                      |
| ИНН       | ИНН СМП                                               |
| Орган     | Контролирующий орган                                  |
| Начало    | Плановая дата начала                                  |
| Окончание | Плановая дата окончания                               |
| Длит.     | Длительность в днях, рассчитывается автоматически     |
| Тип       | Плановая / Внеплановая / Документарная / Выездная     |
| Статус    | Запланирована / В процессе / Завершена / Отменена     |
| Действия  | Редактировать / Удалить                               |

Сортировка: клик по заголовку колонки СМП, Начало, Окончание, Статус.

## Поиск и фильтры

- **Поиск** — по СМП, ИНН, органу и результату одновременно.
- **Статус**, **Тип** — выпадающие списки.
- **Дата от / Дата до** — показываются проверки, чей период **пересекается** с указанным диапазоном.

Кнопки: **Найти**, **Сбросить**.

Фильтры сохраняются в URL, поэтому ссылкой можно поделиться: `?search=ООО&status=completed`.

Клик по пункту меню **«Проверки»** в шапке сбрасывает все фильтры.

## Добавление проверки

1. Кнопка **«Добавить проверку»**.
2. Поля:
   - **СМП** — начните вводить название или ИНН (2+ символа). Появится dropdown.
   - Если СМП нет — **«+ СМП»** открывает модалку создания.
   - **Контролирующий орган** — текст.
   - **Дата начала / окончания** — календарь. Длительность считается автоматически.
   - **Тип проверки**, **Статус** — селекты.
   - **Результат** — необязательно, до 1000 символов.
3. **Создать**. Появится тост об успехе, редирект в список.

## Редактирование проверки

1. Карандаш (✎) в строке таблицы или кнопка **«Редактировать»** в мобильной карточке.
2. Измените поля.
3. **Сохранить**.

## Удаление проверки

1. Корзина (🗑) в строке или **«Удалить»** в карточке.
2. Подтвердите в модалке.

Удаление **soft-delete** — запись остаётся в БД, но не отображается в списке и исключается из экспорта.

## Экспорт в Excel

Кнопка **«Экспорт в Excel»** выгружает **все записи под текущими фильтрами**.

Файл `inspections_YYYY-MM-DD_HHMMSS.xlsx`, колонки — как в таблице + №.

Лимит — 1 000 000 строк на лист. При превышении файл усечён, в конце — предупреждение.

## Импорт из Excel

1. Кнопка **«Шаблон Excel»** — скачать шаблон.
2. Заполнить. Обязательные колонки:
   - Наименование СМП
   - ИНН СМП
   - Контролирующий орган
   - Дата начала проверки
   - Дата окончания проверки
   - Тип проверки
   - Статус
   Необязательно: Результат.
3. Порядок колонок не важен — распознаются по имени.
4. Формат дат: `ДД.ММ.ГГГГ` или `ГГГГ-ММ-ДД`.
5. Тип и статус — кодом (`planned`) или по-русски («Плановая»).
6. Кнопка **«Импорт из Excel»** → выбрать файл.

**Правила:**
- СМП ищется по ИНН. Если не найден — **весь файл откатывается**.
- Ошибка в одной строке, то полный откат.
- Тост покажет строку и поле с ошибкой.
