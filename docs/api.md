# Описание API

REST API реестра плановых проверок СМП.

- **Базовый URL:** `http://localhost:8080/api/v1`
- **Формат:** JSON (UTF-8). Для Excel — `multipart/form-data`.
- **Аутентификация:** отсутствует (см. improvements.md).

## Формат ответов

**Успех:** `{ "data": ... }`

**Список:**
```json
{ "data": [...], "meta": { "total": 42, "page": 1, "per_page": 20, "last_page": 3 } }
```

**Ошибка:**
```json
{ "error": { "code": "validation_failed", "message": "Проверьте поля", "details": { "inn": "ИНН уже используется" } } }
```

**Коды ошибок:**

| Код                 | HTTP | Описание                          |
| ------------------- | ---- | --------------------------------- |
| `validation_failed` | 422  | Ошибка валидации полей            |
| `not_found`         | 404  | Объект не найден                  |
| `duplicate_inn`     | 422  | ИНН уже используется              |
| `bad_format`        | 400  | Неверный формат файла             |
| `import_failed`     | 422  | Ошибки импорта или откат          |
| `empty_file`        | 422  | В файле нет данных                |

## Справочники

**`GET /dictionaries`** — типы проверок и статусы.

```json
{ "data": {
  "inspection_types": [{ "code": "planned", "label": "Плановая" }],
  "statuses": [{ "code": "planned", "label": "Запланирована" }]
}}
```

Типы: `planned`, `unscheduled`, `documentary`, `onsite`.
Статусы: `planned`, `in_progress`, `completed`, `cancelled`.

## СМП

**`GET /smp?search=&limit=20`** — поиск по имени/ИНН. `limit` 1–50.

**`GET /smp/{id}`** — получить один СМП.

**`POST /smp`** — создать. Тело: `{ "name": "ООО Ромашка", "inn": "7701234567" }`. ИНН — 10 или 12 цифр.

## Проверки

**`GET /inspection`** — список с фильтрами и пагинацией.

| Параметр    | Описание                                                        |
| ----------- | --------------------------------------------------------------- |
| `search`    | Поиск по СМП, ИНН, органу, результату                           |
| `status`    | Код статуса                                                     |
| `type`      | Код типа                                                        |
| `date_from` | `YYYY-MM-DD`, пересечение периодов                              |
| `date_to`   | `YYYY-MM-DD`                                                    |
| `page`      | По умолчанию 1                                                  |
| `per_page`  | 1–100, по умолчанию 20                                          |
| `sort`      | `id`, `planned_start_date`, `planned_end_date`, `status`, `smp_name` |
| `order`     | `asc` / `desc`                                                  |

**Элемент ответа:**
```json
{
  "id": 12,
  "smp": { "id": 15, "name": "ООО Ромашка", "inn": "7701234567" },
  "authority": "Роспотребнадзор",
  "planned_start_date": "2025-06-01",
  "planned_end_date": "2025-06-10",
  "planned_duration_days": 10,
  "inspection_type": "planned", "inspection_type_label": "Плановая",
  "status": "completed", "status_label": "Завершена",
  "result": "Нарушений не выявлено.",
  "created_at": "2025-05-20 10:30:00", "updated_at": "2025-06-11 09:15:00"
}
```

`planned_duration_days` вычисляется в SQL, не хранится в БД.

**`GET /inspection/{id}`** — одна проверка.

**`POST /inspection`** — создать. Тело:
```json
{ "smp_id": 15, "authority": "Роспотребнадзор",
  "planned_start_date": "2025-06-01", "planned_end_date": "2025-06-10",
  "inspection_type": "planned", "status": "planned", "result": null }
```
Обязательные: `smp_id`, `authority`, даты, тип, статус. `result` ≤ 1000 символов.

**`PUT /inspection/{id}`** — обновить (тело как у POST).

**`DELETE /inspection/{id}`** — мягкое удаление. Ответ: `204 No Content`.

## Excel

**`GET /inspection/export`** — экспорт отфильтрованного списка в `.xlsx`. Фильтры как у `GET /inspection`, но `page`/`per_page` игнорируются. Лимит 1 000 000 строк на лист.

**`GET /inspection/import/template`** — скачать шаблон `.xlsx`.

**`POST /inspection/import`** — импорт. `multipart/form-data`, поле `file` (`.xlsx`/`.xls`, до 32 МБ).

Успех: `{ "data": { "imported": 3, "total": 3 } }`

Ошибка (422):
```json
{ "error": { "code": "import_failed", "message": "Файл содержит ошибки",
  "details": { "errors": [{ "row": 2, "field": "inn", "message": "ИНН должен содержать 10 или 12 цифр" }], "total": 10 } } }
```

**Правила импорта:**
- Заголовки распознаются по имени, порядок колонок не важен.
- Обязательные: Наименование СМП, ИНН, Орган, Дата начала, Дата окончания, Тип, Статус.
- СМП ищется по ИНН. Если не найден — **полный откат**.
- Ошибка в любой строке — откат всей транзакции.
- Тип/статус принимаются кодом или русской подписью.
- Даты: `ДД.ММ.ГГГГ`, `ГГГГ-ММ-ДД`, `ДД/ММ/ГГГГ`.
